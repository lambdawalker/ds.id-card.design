# Public-school or INEA student credential

[Mexico index](README.md) · `mx.public-school-id`

- **Issuer** Public educational institution / INEA
- **Typical format** varies
- **Evidence** Candidate fields, verify locally
- **Scope** Institution-specific

## Human-readable fields

Check student name, photo, school, enrollment number, level or program and validity period where shown.

## Machine-readable data

Institution-specific barcode or QR presence and payload unverified.
