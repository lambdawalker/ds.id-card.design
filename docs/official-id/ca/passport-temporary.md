# Temporary passport

[Canada index](README.md) · `ca.passport-temporary`

- **Issuer** Canadian mission abroad
- **Typical format** booklet
- **Evidence** ICAO baseline, verify temporary booklet

## Human-readable fields

Passport type, issuing country, surname and given names, passport number, nationality, date of birth, sex marker, expiration date and portrait. Also check issue date, place of birth, authority, signature and any country-specific identifier on the applicable edition.

## Machine-readable data

The passport MRZ carries document type, issuing state, names, document number, nationality, date of birth, sex marker, expiration date, optional issuer data and check digits. Verify the temporary booklet separately for any chip.
