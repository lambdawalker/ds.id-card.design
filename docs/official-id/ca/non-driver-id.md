# Provincial or territorial photo identification card

[Canada index](README.md) · `ca.non-driver-id`

- **Issuer** Province or territory
- **Typical format** card
- **Evidence** Standard reference and candidate visual fields
- **Scope** Verify product availability by jurisdiction

## Human-readable fields

Check name, date of birth, portrait, address, identification number, issue and expiry, signature and any physical descriptors.

## Machine-readable data

AAMVA describes PDF417 for adopting jurisdictions. Check actual card technology and field set by province or territory.
