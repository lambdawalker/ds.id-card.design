# Possession and Acquisition Licence (PAL)

[Canada index](README.md) · `ca.firearms-pal`

- **Issuer** RCMP Canadian Firearms Program
- **Typical format** card
- **Evidence** Candidate fields, verify against specimen
- **Scope** Restricted privileges are a variant

## Human-readable fields

Check name, portrait, licence number, expiration and authorized firearm classes or conditions on the PAL edition.
