# Advance parole travel document

[United States index](README.md) · `us.travel-advance-parole`

- **Issuer** USCIS
- **Typical format** varies
- **Evidence** Candidate fields, verify against specimen
- **Scope** Standalone and eligible combined EAD variants

## Human-readable fields

Check name, photograph where present, USCIS or case identifiers, document type, validity, entry terms and any advance-parole statement on eligible combination cards.

## Machine-readable data

Verify the standalone document and eligible EAD combination card independently. Code presence and payload unverified for the standalone form.
