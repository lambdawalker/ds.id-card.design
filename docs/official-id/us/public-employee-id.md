# State or local public employee ID

[United States index](README.md) · `us.public-employee-id`

- **Issuer** Issuing government agency
- **Typical format** varies
- **Evidence** Candidate fields, verify locally
- **Scope** Agency-specific scope

## Human-readable fields

Check name, portrait, employee or badge number, department, role, issuer and expiration. Record access indicators or signature only for the documented edition.

## Machine-readable data

Agency-specific. Verify barcode or smart-card presence, and distinguish an access identifier from personal data.
