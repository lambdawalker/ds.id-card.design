# Transportation Worker Identification Credential (TWIC)

[United States index](README.md) · `us.transport-worker`

- **Issuer** TSA
- **Typical format** card
- **Evidence** Candidate fields, verify against specimen

## Human-readable fields

Check name, portrait, expiration, credential or serial number and TWIC program markings.

## Machine-readable data

Check smart-card credential identifier and any certificate or biometric categories against TSA's applicable technical profile. No field-level payload established here.
